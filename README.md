# Flyvora — Explore More

India-wide travel discovery and trip-planning website built with React, TypeScript, and Vite.

## Run Locally

**Prerequisites:** Node.js 20.19+ (or 22.12+)

```sh
npm install
npm run dev
```

Open http://localhost:3000 in your browser. The site uses local sample data and does not require an API key to start.

The main sections are available at their own URLs: `/destinations`, `/hotels`, `/tours`, `/transport`, `/guides`, `/planner`, `/budget`, `/about`, and `/contact`. The navbar dropdowns open on hover; select a menu item to navigate.

To check types and create a production build:

```sh
npm run lint
npm run build
```
